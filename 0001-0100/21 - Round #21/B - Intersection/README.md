# B. Intersection

**Submission:** https://codeforces.com/contest/21/problem/B

**Limits:** 1 second / 256 megabytes

## Problem Statement

The first line of the input contains three integer numbers A 1 ,ΓÇë B 1 ,ΓÇë C 1 separated by space. The second line contains three integer numbers A 2 ,ΓÇë B 2 ,ΓÇë C 2 separated by space. All the numbers are between -100 and 100, inclusive.

## Output
